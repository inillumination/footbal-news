# Football Media

Автоматизированное футбольное медиа на WordPress с отдельными сервисами для обработки новостей и футбольных данных.

## Цель первой версии
За 14 дней подготовить MVP: собственная тема WordPress, новости, ограниченная AI-автоматизация, расписание и результаты матчей, базовый матч-центр и SEO.

## Архитектура
- WordPress: CMS и публичный сайт.
- `football-media-core`: собственный плагин с футбольными сущностями и интеграциями.
- Python News Engine: сбор и подготовка новостей.
- Football Data Engine: синхронизация футбольных данных из внешнего API.
- MariaDB: база WordPress.
- PostgreSQL: данные News Engine и футбольного сервиса.
- Redis/Celery: фоновые задачи и расписание.

## Важные правила
- Не хранить секреты в Git.
- Не публиковать неподтверждённые факты автоматически.
- Не копировать защищённые тексты и изображения.
- Проверять доступность данных и лимиты API до проектирования функций.
- Перед этапами с изменением данных создавать и проверять резервную копию MariaDB, PostgreSQL и файлов WordPress, а рабочее состояние фиксировать в Git; порядок восстановления описан в docs/DEPLOYMENT.md.

Подробности находятся в `docs/`.
