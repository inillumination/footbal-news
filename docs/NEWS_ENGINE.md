# News Engine

## MVP pipeline
1. Список разрешённых источников.
2. RSS/API collector.
3. Сохранение исходной записи и URL.
4. Нормализация.
5. Дедупликация.
6. Извлечение проверяемых фактов.
7. Сверка источников.
8. AI-черновик на русском.
9. Проверка фактов, языка, повторов и источников.
10. Создание WordPress draft или публикация по строгим правилам.

## Безопасная политика
- По умолчанию создавать черновики.
- Автопубликация только для заранее разрешённых категорий и прошедших проверки материалов.
- Слухи и противоречивые сведения — ручная проверка.
- Не копировать исходные статьи.
- Не использовать фото без подтверждённых прав.
- Сохранять ссылки на первоисточники.
- Предусмотреть глобальный kill switch.

## Условия автопубликации
- Единственный флаг NEWS_AUTO_PUBLISH_ENABLED хранится в серверной конфигурации News Engine и по умолчанию имеет значение false. Отсутствующее или некорректное значение также означает false.
- Список разрешённых категорий и источников пуст, пока их явно не утвердили; изменение флага и решение о публикации должны попадать в аудит.
- Автопубликация допустима только для категории из списка разрешённых и после успешного прохождения всех редакционных и технических проверок.
- Каждое ключевое утверждение должно подтверждаться первичным источником либо двумя независимыми источниками из утверждённого списка. Перепечатки одного сообщения не считаются независимыми.
- Слухи, противоречия, неподтверждённые суммы или даты, отсутствующие ссылки, ошибка любой проверки или неподтверждённые права на используемое изображение оставляют материал черновиком для ручной проверки.
- Уверенность модели сама по себе не подтверждает факт. Неопределённый результат проверки трактуется как отказ в автопубликации.
- В журнале хранить версию правил, использованные источники, статусы проверок, решение, время и причину ручного исправления или отмены публикации.
