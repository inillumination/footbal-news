# News Engine

## MVP pipeline
1. Список разрешённых источников.
2. RSS/API collector.
3. Сохранение исходной записи и URL.
4. Нормализация.
5. Дедупликация.
6. Извлечение проверяемых фактов.
7. Сверка источников.
8. AI-черновик на русском.
9. Проверка фактов, языка, повторов и источников.
10. Создание WordPress draft или публикация по строгим правилам.

## Безопасная политика
- По умолчанию создавать черновики.
- Автопубликация только для заранее разрешённых категорий и прошедших проверки материалов.
- Слухи и противоречивые сведения — ручная проверка.
- Не копировать исходные статьи.
- Не использовать фото без подтверждённых прав.
- Сохранять ссылки на первоисточники.
- Предусмотреть глобальный kill switch.
