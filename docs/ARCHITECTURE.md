# Architecture

## Компоненты
1. WordPress — CMS и публичный сайт.
2. Тема `football-media` — только представление.
3. Плагин `football-media-core` — таксономии, метаданные, REST-интеграции и WordPress-специфичная логика.
4. Python News Engine — сбор и редакционная подготовка новостей.
5. Football Data Engine — получение футбольных данных от провайдера.
6. MariaDB — данные WordPress.
7. PostgreSQL — данные Python-сервисов.
8. Redis/Celery — фоновые задания.

## Поток новостей
Разрешённый источник -> загрузка -> нормализация -> дедупликация -> извлечение фактов -> проверка -> AI-черновик -> контроль качества -> WordPress.

## Поток матчевых данных
Поставщик API -> плановая синхронизация -> проверка и нормализация -> база/кэш -> WordPress.

## Принципы
- Секреты только в окружении.
- Внешние API вызываются сервером, не браузером.
- На страницах не должно быть прямого запроса к провайдеру при каждом просмотре.
- Компоненты должны иметь health checks и понятные логи.
