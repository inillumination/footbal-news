# Deployment

## Перед production
- Проверить доступ к VPS и домену.
- Проверить DNS и HTTPS.
- Использовать отдельные сильные пароли.
- SSH по ключам; ограничить доступ.
- Настроить firewall.
- Хранить `.env` вне Git.
- Настроить резервное копирование БД и файлов во внешнее хранилище.
- Проверить восстановление из резервной копии.
- Настроить health checks и уведомления.
- Не выполнять миграции на production без backup.

## Не выполнять автоматически
Codex не должен менять DNS, firewall, SSH, production secrets или удалять данные без отдельного подтверждения пользователя.
