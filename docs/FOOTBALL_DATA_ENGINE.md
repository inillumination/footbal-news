# Football Data Engine

## MVP
- Список выбранных турниров.
- Расписание.
- Результаты.
- Статус матча.
- LIVE-счёт, если предоставляется.
- Основные события, если предоставляются.
- Турнирная таблица, если предоставляется.
- Страница матча.

## До разработки
Проверить каждую выбранную пару турнир/сезон и несколько подходящих матчей. Даже если провайдер публикует отметку о покрытии поля, она не гарантирует его в каждом ответе; проверить реальные ответы, частоту, задержки, лимиты и условия хранения/отображения. Не включать неподтверждённые поля в обязательную схему.

## Синхронизация
- Запланированные матчи обновлять редко.
- LIVE-матчи обновлять чаще в пределах тарифных лимитов.
- Завершённые матчи синхронизировать финально.
- Кэшировать ответы.
- Хранить время последнего успешного обновления.
- Не выполнять запрос к внешнему API при каждом просмотре страницы.

## Вне MVP
Коэффициенты, расширенный xG, продвинутые рейтинги игроков и глубокая историческая статистика.
