# Design Specification — предварительная

## Направление
Современное спортивное медиа: редакционная сетка, выразительные заголовки, ясная иерархия, быстрый доступ к матчам и новостям.

## Шаблоны MVP
1. Главная: главная публикация, свежие новости, блок матчей, блок турниров.
2. Статья: заголовок, лид, изображение с правами, автор/редакция, дата, текст, источники, похожие материалы.
3. Категория: заголовок, список материалов, пагинация.
4. Матч: команды, статус/счёт, время, события, доступные составы и статистика.
5. Турнир: таблица, матчи, результаты.
6. Клуб: название, эмблема при наличии прав, состав/матчи/новости.

## UX
- Mobile-first.
- Хорошая читаемость.
- Не перегружать рекламой.
- Явно показывать время обновления live-данных.
- Не показывать отсутствующую статистику как нули.
- Сначала согласовать макеты, затем реализовывать.
