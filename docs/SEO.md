# SEO — MVP checklist

- ЧПУ и стабильные URL.
- Один H1 на страницу.
- Уникальные title и description.
- Canonical.
- XML Sitemap.
- Robots.txt.
- Open Graph.
- Breadcrumbs.
- NewsArticle structured data для статей.
- SportsEvent structured data для матчей при корректных данных.
- Внутренние ссылки между новостями, клубами и турнирами.
- Search Console и Яндекс Вебмастер.
- Проверка мобильной версии и скорости.

Разметка не гарантирует расширенные результаты или включение в новостные поверхности.
